# Form Project

This project is a simple HTML form with a bordered card style.

## 📝 HTML Tags Used

- `<form>` → Defines the form itself.
- `<fieldset>` → Groups related fields inside the form with a border.
- `<legend>` → Caption/heading for the fieldset (appears on the border).
- `<div>` → Used as a container (optional for card styling).
- `<h4>` → Small heading inside the form/card.
- `<label>` → Labels for form input fields.
- `<input>` → For taking user inputs.
  - `type="text"` → Text input fields.
  - `type="email"` → Email input field.
  - `type="number"` → Number/phone input field.
- `<select>` → Dropdown menu for choosing an option.
  - `<option>` → Individual choices in the dropdown.
- `<br>` → Line break for spacing (used in simple layouts, though CSS is better).
- `<button>` or `<input type="submit">` → For submitting the form.
